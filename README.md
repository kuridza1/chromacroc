ChromaCroc

Google Developer Group Hackathon – Build with AI (AI for All)

Overview

Did you know that crocodiles have a natural red-green vision deficiency? Inspired by this, ChromaCroc is an AI-powered mobile application designed to improve accessibility for people with color vision impairments.

The application provides users with fast, clear, and context-aware answers to a simple but essential question:
“What color is this?”

Problem

People with color blindness often struggle with everyday tasks that rely on accurate color perception, such as:

Distinguishing between similar shades (e.g., red vs. brown)
Assessing whether food (like meat) is properly cooked
Interpreting visual cues in real-world environments

Most existing solutions focus only on raw color detection, without considering environmental context or user-specific needs.

Solution

ChromaCroc introduces an intelligent AI assistant that goes beyond basic color recognition. It incorporates:

Contextual analysis (surroundings, object type)
Lighting conditions and shadows
Opacity and color intensity
User-specific color blindness profiles

The result is a short, precise, and meaningful answer, tailored to real-world scenarios.

Key Features
AI-powered color recognition
Context-aware responses (not just raw color values)
Adaptation to different types of color vision deficiency
Real-world usability (e.g., food readiness detection)
Clean and minimal user interaction
Example Use Case

A user unsure whether meat is fully cooked can point their camera at it. Instead of just identifying “red” or “brown,” ChromaCroc provides a clearer interpretation, such as:

“The meat appears undercooked based on its color and texture.”

Tech Stack
Android Studio – Mobile application development
Google AI Studio – Model prototyping and integration
Google AI Development Kit (ADK) – Agent-based architecture for intelligent responses
How It Works
User captures or uploads an image
AI agent analyzes visual data
Contextual factors are evaluated
A concise, human-readable answer is generated
Vision

ChromaCroc aims to make everyday decisions easier and more reliable for people with color vision deficiencies, contributing to a more inclusive and accessible world through AI.
